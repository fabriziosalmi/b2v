# Security Policy

We take security seriously. If you discover any security vulnerability in our project, please report it to us so we can address it promptly.

## Vulnerability Disclosure Policy

We welcome responsible disclosure of security vulnerabilities. Please follow these steps when reporting a vulnerability:

1. **Report the vulnerability:** Contact us immediately via [Insert appropriate contact method, e.g., security@example.com] or by filing an issue on GitHub.
2. **Provide details:** Include a clear description of the vulnerability, steps to reproduce it, and any relevant context. Do not disclose sensitive information that could put users or systems at risk.
3. **Cooperation:** We will work with you to address the vulnerability responsibly.
4. **Timeline:** We aim to address reported vulnerabilities as quickly as possible, while ensuring the security of our systems and users.
