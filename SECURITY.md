# Security Policy

We welcome security researchers to report vulnerabilities found in our software.

## Responsible Disclosure Policy

If you discover a vulnerability, please follow these guidelines for responsible disclosure:

1. **Report the vulnerability:** Please report the vulnerability privately to [Security Contact/Email Address].
2. **Provide details:** Include a clear description of the vulnerability, steps to reproduce it, and any relevant evidence.
3. **Timeline:** We will work with you to establish a timeline for remediation.
4. **Confidentiality:** We are committed to handling all reported information with the utmost confidentiality.

Please do not disclose the vulnerability publicly until we have had sufficient time to address it.
