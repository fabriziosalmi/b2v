# Getting Started with B2V

## Prerequisites
- Node.js (version 18+)
- Rust (version 1.70+)

## Installation

### Frontend
```bash
npm install -g @b2v/cli
```

### Backend
```bash
cargo install b2v-cli
```

## Basic Usage

### Frontend
```bash
b2v-cli init my-project
```

### Backend
```bash
b2v-cli new my-backend
```
